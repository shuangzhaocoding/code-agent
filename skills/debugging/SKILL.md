# Skill: debugging

系统化定位和修复软件缺陷。用户描述错误、异常、失败测试、行为回归或运行时问题时使用。

# 指令

1. 先复现问题，记录完整错误信息、触发条件、运行环境和预期行为。
2. 先检查相关代码、调用链、配置和最近变更，不凭症状直接猜修复方案。
3. 将问题缩小到最小可验证假设，每次只验证一个关键原因。
4. 优先修复根因，避免通过吞异常、放宽校验或增加无关重试来掩盖问题。
5. 为修复补充覆盖回归场景的测试，至少包括用户报告的失败路径和一个相邻边界条件。
6. 运行相关测试、类型检查和 lint；无法运行时说明具体原因。
7. 最后总结根因、修改文件、验证命令和剩余风险。

# 约束

- 不删除或回退用户已有的无关修改。
- 不在日志、错误信息或测试中暴露密钥、令牌和个人数据。
- 对并发、缓存、时区、权限和输入边界问题进行专项检查。
